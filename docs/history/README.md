# Archive — historical documents

**Nothing in this directory is current guidance.**

These files are preserved as a record of how MNEMOS was designed and built:
release charters, plans, and review reports from earlier versions. They
describe the intent and state of the project *at the time they were written*,
and they have deliberately **not** been updated to match the current release.
Several of them describe subsystems, formats, and schemas that have since
changed or been retired.

Read them for context and rationale. Do not follow them as instructions.

For anything you intend to act on, use the live documentation instead:

| You want | Read |
|---|---|
| How to install and run MNEMOS | [`docs/INSTALL.md`](../INSTALL.md) and [`DEPLOYMENT.md`](../../DEPLOYMENT.md) |
| What the system does today | [`docs/SPECIFICATION.md`](../SPECIFICATION.md) |
| The API surface | [`API_DOCUMENTATION.md`](../../API_DOCUMENTATION.md) |
| What changed, release by release | [`CHANGELOG.md`](../../CHANGELOG.md) |
| The development narrative | [`EVOLUTION.md`](../../EVOLUTION.md) |
| What is planned next | [`ROADMAP.md`](../../ROADMAP.md) |
